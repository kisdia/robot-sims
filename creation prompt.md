I want to create a web based game like isometric virtual lab for robots.
The purpose is for universities and companies to design and their own virtual lab or factory and add the representation of their real robots.
This isometric envrionment the users can add their rooms, furniture, equipment, machines for a library of assets similar to the game sims.

For the robots users can check status of these robots like where is it currently (in the lab, on field trial etc), create booking for the robot, check what equipment is installed on the robot, maintenance status and log, warranty status, manufacturer, hardware version, software version. 

I have added some example images of the clean modern look for the simulator.

I have added some example isometric images of robots in assets folder.

This will be a free interface offered by Autodiscovery, hosted on the Autodiscovery Linux server.
